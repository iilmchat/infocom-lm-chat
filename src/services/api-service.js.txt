Ключевые улучшения
Надежность: Все запросы используют fetchWithRetry с таймаутами

Обработка ошибок: Различные типы ошибок обрабатываются отдельно

Диагностика: Добавлены методы getStatus() и resetState()

Потоковая передача: Улучшена обработка чанков и буферизация

Валидация: Проверка всех входных и выходных данных

Логирование: Понятные логи с эмодзи для быстрой диагностики

Безопасность: Ограничение размера аккумулированного текста

Fallback-механизмы: Эмбеддинги генерируются локально при ошибке
