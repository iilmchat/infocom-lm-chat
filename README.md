# Infocom LM Chat Pro v5.0

Современный веб-чат для работы с локальными LLM-моделями через LM Studio, с поддержкой RAG (Retrieval-Augmented Generation), Code Review, генерации тестов, игр и системой достижений.

## 🖥️ Системные требования

- **Современный браузер**: Chrome 90+, Firefox 88+, Edge 90+, Safari 15+
- **LM Studio**: Установленный и запущенный локальный сервер
- **Оперативная память**: 4+ ГБ (для работы с большими моделями)
- **Дополнительно**: Поддержка ES Modules (type="module")
