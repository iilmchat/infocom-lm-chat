🚀 Быстрый старт

  1. Откройте чат — дождитесь подключения к серверу (индикатор в правом верхнем углу).
  2. Напишите сообщение — введите текст и нажмите Ctrl+Enter или кнопку Отправить.
  3. Прикрепите файл — нажмите 📎 или перетащите файл в окно. Выберите режим:
    • Вложение — файл прикрепляется к сообщению
    • RAG документ — файл добавляется в контекст для последующих вопросов

🔧 Основные функции

💬 Диалоги

  • Все диалоги сохраняются автоматически в браузере.
  • Слева — список диалогов. Нажмите на любой, чтобы переключиться.
  • Кнопка + Новый создаёт новый диалог.
  • ✏️ — переименовать диалог, 🗑️ — удалить.

📚 RAG (Retrieval-Augmented Generation)

RAG позволяет загружать документы, чтобы модель отвечала на основе их содержания.

Как использовать:

  1. Нажмите 📚 RAG документ или перетащите файлы в окно.
  2. Выберите режим RAG документ (клавиша 2 при перетаскивании).
  3. После загрузки задайте вопрос — модель использует документы в ответе.

Лимит: до 500 чанков (фрагментов текста). При заполнении используйте кнопку 🗑️ RAG для очистки.

🔍 Code Review

Нажмите 🔍 Code Review — модель проанализирует ваш код (из поля ввода или прикреплённых файлов) и выдаст рекомендации.

🧪 Генерация тестов

Нажмите 🧪 Тесты — модель сгенерирует unit-тесты для вашего кода.

🎨 Темы

Нажмите 🎨 в верхней панели для переключения тем:

  • 🌙 Тёмная (по умолчанию)
  • ☀️ Светлая
  • 🟡 Монохромная (Monokai)

💾 Экспорт

Нажмите 💾 Экспорт (Ctrl+E) для сохранения диалога в форматах TXT, JSON или Markdown.

⌨️ Горячие клавиши

  • Ctrl+Enter — отправить сообщение
  • Shift+Enter — новая строка
  • Escape — закрыть модальное окно / отменить ответ
  • / — фокус на поле ввода
  • Ctrl+W — открыть/закрыть информацию
  • Ctrl+E — экспорт

📂 Поддерживаемые форматы файлов

📝 Разметка: .html .css .xml .json .csv .md .txt

❓ Часто задаваемые вопросы

Что делать, если сервер недоступен?
Проверьте подключение к интернету и доступность сервера. Индикатор статуса покажет, доступен ли сервер.

RAG не работает, почему?
Убедитесь, что вы загрузили документы в режиме RAG документ (не вложение). Также проверьте, не превышен ли лимит в 500 чанков.

Как удалить прикреплённые файлы?
Нажмите ✕ рядом с именем файла в области прикреплённых файлов под полем ввода.

Куда сохраняются мои диалоги?
Все данные хранятся локально в вашем браузере (localStorage). При очистке истории браузера диалоги могут быть потеряны.

🔒 Вся обработка происходит на серверной стороне. Диалоги хранятся только в вашем браузере.
