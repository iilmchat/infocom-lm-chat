12. Документация API (краткая) 2.2
POST /api/projects/{projectId}/run-bat
Тело: отсутствует.

Ответ (успех): { "success": true, "data": { "log": "вывод скрипта" } }

Ошибки: 400 (закрытый проект, скрипт не найден), 403 (нет прав), 404 (проект не найден), 500 (таймаут и др.).

POST /api/projects/{projectId}/code
Тело: { "path": "src/Program.cs", "content": "using System; ..." }

Ответ: { "success": true, "data": { "fileId": "src/Program.cs" } }

Ошибки: 400 (неверный путь, закрытый проект), 403, 404.

POST /api/projects/{projectId}/commit
Тело: { "message": "Add new feature" }

Ответ: { "success": true, "data": { "commitHash": "a1b2c3..." } }

Ошибки: 400 (нет изменений, закрытый проект), 403, 404, 500 (Git не установлен и т.п.).

13. Архитектурные решения
Сервис IaAssistantService инкапсулирует всю логику, используя IProjectService для проверок и IAuditService для логирования.

Вспомогательные классы PathHelper и GitProcessHelper обеспечивают безопасную работу с файловой системой и Git через Process.

Конфигурация вынесена в ProjectStorageSettings для гибкости.

Асинхронность всех операций с корректными таймаутами.
