Инструкция по запуску обновлённого проекта в Windows
Убедитесь, что у вас установлены:

.NET Core 3.1 SDK

MS SQL Server (или SQL Server Express)

Любой браузер (Chrome, Edge, Firefox)

Настройка строки подключения
Откройте файл appsettings.json и укажите корректную строку подключения к вашей БД:

json
"ConnectionStrings": {
    "DefaultConnection": "Server=(localdb)\\mssqllocaldb;Database=ProjectManagerDB;Trusted_Connection=True;MultipleActiveResultSets=true"
}
(или замените на свои параметры).

Применение миграций (если база ещё не создана)
Откройте командную строку в корневой папке проекта и выполните:

text
dotnet ef database update
Если миграций нет, создайте их:

text
dotnet ef migrations add InitialCreate
dotnet ef database update
Запуск сервера
Выполните в той же командной строке:

text
dotnet run
Сервер запустится на адресах, указанных в выводе (обычно https://localhost:5001 и http://localhost:5000).

Открытие тестового клиента

Откройте браузер и перейдите по адресу https://localhost:5001/test-client.html (или http://localhost:5000/test-client.html, в зависимости от настроек).

Если сервер использует самоподписанный сертификат, браузер может показать предупреждение — разрешите переход.

В поле «Адрес сервера» введите базовый URL вашего API (например, https://localhost:5001).

Получите токен, выполнив запрос POST /api/auth/login или POST /api/auth/register через клиент.

Вставьте полученный токен в поле «Токен» и нажмите «Сохранить».

Работа с клиентом

Вы увидите список всех эндпоинтов.

Заполните параметры (если они есть в URL) и тело запроса (при необходимости).

Нажмите «Отправить» — ответ отобразится в блоке под кнопкой.
