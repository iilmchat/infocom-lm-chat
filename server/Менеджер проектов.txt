
Необходимо реализовать web-приложение

Наименование: "Менеджер ИТ-проектов"
Описание: 
Необходимо реализовать приложение которое будет вести ИТ-проект от начала до конца с использованием ИИ-агентов

Технологии:
сервер PostgreSQL + donet core 3.1
клиент angular

Необходимые функции:
1. авторизация
2. ведение проектов (CRUDL)
2.1. При добавлении нового проекта задаётся только наименование
2.2. При редактировании проекта обеспечить возможность прикреплять и создавать txt-документы

поддерживаемые виды документов с последовательной доступностью: 
1. "Исходные данные"
2. "Проект"
3. "ТТ"
4. "ПиМ ПСИ"

Если Создан или прикреплен "ИД", тогда есть возможность создать "Проект" и т.д.


создать (CRUDL) проект + закрыть проект.
//добавить (CRUDL) асистентов типа "аналитик" для проекта , "аналитик" для ТТ, "архитектор", "разработчик",  "тестировщик"

добавить документы определенного типа: "ИД", "Проект", "ТТ", "ПиМ ПСИ", "ЦБИ"

Задачи для аналитика по проектам:
подготовить Проект и пояснительную записку на базе ИД  
отредактировать Проект на базе пояснительной записки к проекту

Задачи для аналитика по ТТ:
подготовить ТТ и пояснительную записку на базе Проекта и замечаний
отредактировать ТТ на базе пояснительной записки к ТТ и замечаний

Задачи для архитектора по ТТ:
создать документы:
1. используемые технологии
2. структура проекта
3. структура файловой системы
4. этапы разработки (задачи)

аркестрант запускает .bat (структура файловой системы)
аркестрант запускает юнит тесты для каждой версии

Задачи для разработчика по задаче:
1. Пишет код в файловую систему
2. Коммитит
