📋 Инструкция по использованию
🚀 Быстрый старт
Сохраните файл как Index.html

Откройте в браузере

Сервер должен быть запущен на http://localhost:8032

🎯 Основные функции
Функция	Описание
Авто-тест	🤖 Автоматическая проверка API с предустановленными данными
Ручная проверка	👆 Проверка с введёнными вручную параметрами
Запуск всех тестов	🚀 Последовательная проверка всех API
Фильтры	По HTTP методу, статусу и тексту
Статистика	Отображение прогресса и результатов
📊 Статусы проверок
Статус	Значение
⏳ Ожидает	Метод ещё не проверен
✅ Успешно	Метод отработал корректно
❌ Ошибка	Метод вернул ошибку
👆 Ручная	Проверено вручную
⌨️ Горячие клавиши
Клавиша	Действие
Ctrl+Enter	Запустить все тесты
Esc	Закрыть все раскрытые тела запросов
📝 Особенности
Автоматическое сохранение — результаты тестов сохраняются в localStorage

Динамические переменные — {roomId} и {chatId} подставляются автоматически

Индикация статуса сервера — отображается в шапке

Прогресс-бар — показывает общий прогресс тестирования
