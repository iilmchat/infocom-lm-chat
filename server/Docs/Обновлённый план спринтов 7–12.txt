Спринт 10: Разработчик – выполнение задач и подтверждение
Цель: Поэтапное выполнение задач разработчиком с возможностью переделки.

Задачи:

Расширить DeveloperTaskService

Метод RunTaskAsync(projectId, taskId, userId, isAdmin, ct):

Найти задачу, статус Pending или Rejected.

Собрать контекст: описание задачи, комментарий владельца, входные документы (архитектурные).

Получить промт для выполнения ("Developer_Task").

Использовать модель разработчика.

Вызвать LM Studio с create_file для создания файлов (тип определяется из задачи, например КОД, КОНФ, ДР).

Постобработка.

Создать документы и файлы.

Обновить статус задачи на Completed.

При ошибке – документ ошибки (ERR_КОД и т.п.) и статус Rejected (или Pending для повторного запуска).

Метод ApproveTaskAsync – установить статус Approved, после чего автоматически запустить следующую задачу (если есть и план утверждён).

Метод RejectTaskAsync – принять комментарий с недочётами, статус Rejected, сохранить комментарий в задачу.

Контроллер

POST /api/projects/{projectId}/assistant/developer/tasks/{taskId}/run

POST /api/projects/{projectId}/assistant/developer/tasks/{taskId}/approve

POST /api/projects/{projectId}/assistant/developer/tasks/{taskId}/reject с телом { "comment": "текст" }.

Логирование и аудит

Критерии:

Последовательное выполнение задач с ручным подтверждением.
