# Ручное тестирование Infocom LM Chat Pro v6.2

Чек-лист для проверки клиентской части в браузере. Дополняет
[static smoke](../development/reports/v6.2/smoke-01-static.md); runtime
выполняет тестировщик.

## Окружение

- Статика: `http://localhost:8033/`
- LM Studio: `http://127.0.0.1:8034`
- .NET API: `http://127.0.0.1:8032` (опционально)
- Браузер: Chrome/Edge/Firefox последних версий, DevTools открыт
- Чистый профиль или `localStorage` очищен — для проверки первого запуска

**Легенда:** ✅ пройдено · ❌ провалено · ⚠️ предупреждение · ⬜ не проверено

## 6. Общие проверки

- [ ] В консоли нет `Uncaught`/`TypeError` на всех страницах.
- [ ] Нет 404 по `vendor/*` (highlight, marked, purify, mammoth, html2pdf).
- [ ] Все модалки закрываются по ✕, overlay и `Escape`.
- [ ] Переключение тем не ломает кнопки `.btn-*`.
- [ ] После reload сохраняются тема, ширина sidebar, текущий диалог.
- [ ] При остановленном API `8032` приложение остаётся работоспособным
  (известный поток ошибок — KI-025).

## 7. Если тест провален

1. Зафиксируйте ID проверки, шаги, ожидаемый и фактический результат.
2. Приложите скриншот и текст ошибки из консоли.
3. Заведите KI в [KNOWN_ISSUES.md](../KNOWN_ISSUES.md) по шаблону
   (приоритет, статус, файлы).
4. Не закрывайте KI без подтверждения в коде и повторного прогона.
