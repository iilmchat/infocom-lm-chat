# Руководство пользователя

Краткая инструкция по Infocom LM Chat Pro v6.2. Полный список проблем и
ограничений — в [KNOWN_ISSUES.md](../KNOWN_ISSUES.md).

## 1. Перед началом

Для работы нужны:

- **LM Studio** на `http://127.0.0.1:8034` — обязателен для ответов модели;
- **статический сервер** на `http://localhost:8033` — раздаёт SPA;
- **.NET API** на `http://127.0.0.1:8032` — опционален; без него недоступны
  комнаты, приватные чаты и админка.

Откройте `http://localhost:8033/`. Если LM Studio не запущен, чат не сможет
генерировать ответы — проверьте соединение в настройках (⚙️).

## 2. Как отправить сообщение

1. Выберите диалог в sidebar или нажмите **«+ Новый»**.
2. Введите текст в поле внизу.
3. Нажмите **«Отправить»** или `Ctrl+Enter`.
4. `Shift+Enter` — перенос строки, `Ctrl+↑`/`Ctrl+↓` — история ввода.

Во время генерации кнопка отправки заменяется на **«Стоп»** — нажатие
останавливает ответ. Ответ можно отредактировать, скопировать,
перегенерировать или сохранить в экспорт.

## 3. Как загрузить RAG-документ

RAG добавляет содержимое файлов в контекст модели.

1. Нажмите кнопку **📚** или перетащите файл в окно чата.
2. Выберите режим **«RAG документ»** (не «Вложение»).
3. Дождитесь разбиения на чанки; прогресс виден в статистике RAG.
4. Задайте вопрос — в ответе появятся источники с релевантностью.

Ограничения: до **500 чанков**, размер файла — до **10 МБ**. Поддерживаются
TXT, MD, PDF, DOCX и другие текстовые форматы. Очистить RAG — кнопка 🗑️.

## 4. Как сменить тему

Нажмите **🎨** в верхней панели. Темы переключаются по кругу:

- 🌙 **dark** — по умолчанию;
- ☀️ **light**;
- 🟡 **monokai**.

Выбор сохраняется в `localStorage` (`chat_theme`) и применяется при
следующем открытии. Если тема «залипла», очистите ключ `chat_theme` в
DevTools и перезагрузите страницу.

## 5. Вложения и файлы

- Режим **«Вложение»** прикрепляет файл к конкретному сообщению.
- Режим **«RAG документ»** добавляет файл в общий контекст.
- Перетаскивание: выберите режим клавишами `1` (вложение) или `2` (RAG),
  либо наведите на нужную зону.

## 6. Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Enter` | Отправить сообщение |
| `Shift+Enter` | Перенос строки |
| `Ctrl+↑` / `Ctrl+↓` | История ввода |
| `Escape` | Закрыть модалку / отменить ответ |
| `/` | Фокус на поле ввода |
| `Ctrl+W` | Открыть/закрыть Вики |
| `Ctrl+E` | Экспорт диалога |
| `Ctrl+S` | Окно «Поделиться» |

Полная таблица — в [README.md](../../README.md#горячие-клавиши).

## 7. Если что-то не работает

- **Модель не отвечает** — проверьте LM Studio на `8034` и кнопку
  «🔍 Проверить» в настройках.
- **Нет комнат/приватных чатов** — запустите .NET API на `8032` или
  работайте в режиме одиночного чата (см. KI-025).
- **RAG не отвечает по документу** — проверьте режим «RAG документ»,
  лимит 500 чанков и размер файла.
- **Ошибка в консоли** — откройте DevTools (F12), сохраните текст ошибки
  и приложите к описанию проблемы.

## 8. Куда сообщить о проблеме

Заведите запись в [KNOWN_ISSUES.md](../KNOWN_ISSUES.md) по шаблону KI
или опишите шаги воспроизведения в issue репозитория.
